Based on the constraints of small spatial resolution (9×9) and many channels (>30), the recommended architecture is a customized **Isotropic InceptionNeXt**.

While standard ResNet is the "safe" baseline for board games (AlphaZero/dlshogi), InceptionNeXt is theoretically better suited for Shogi's game mechanics if adapted correctly.

## Why InceptionNeXt over ConvNeXt?

Shogi has powerful "ranging pieces" (Rook, Lance, Bishop) that move across the entire board in straight lines. [1]

The InceptionNeXt kernel decomposition maps naturally to this:

- A `1×9` convolution perfectly models a Rook or Lance moving across a rank/file in a single layer.
- A `3×3` branch captures local interactions (King safety, Pawn heads).
- This matches the **inductive bias** of Shogi moves better than a square `7×7` block.

## Critical Modifications for 9×9 Input

Standard ConvNeXt/InceptionNeXt models are designed for large images (224×224) and use aggressive downsampling (stride 4, then stride 2). **You must remove all downsampling.**

> If you downsample a 9×9 board even once, you get a 4×4 grid, destroying all tactical information.

## Proposed Architecture

### 1. Stem (Input Layer)

Do not use the standard "Patchify" stem (4×4, stride 4). Use a simple projection that preserves the 9×9 size:

```
Conv2d(in_channels, hidden_dim, kernel_size=3, padding=1, stride=1)
LayerNorm (channels_last style)
```

### 2. Backbone (Body)

Stack 10–20 identical **Isotropic** blocks. Resolution stays 9×9 throughout.

### 3. Block Design (InceptionNeXt style)

Split channels into 4 parallel depthwise branches:

| Branch | Operation | Captures |
| :--- | :--- | :--- |
| Identity | Pass-through | Unchanged features |
| Local | DepthwiseConv2d(3×3) | Local tactics (Gold/Silver/Pawn) |
| Horizontal | DepthwiseConv2d(1×9) | Rank-based moves (Rook/Lance) |
| Vertical | DepthwiseConv2d(9×1) | File-based moves (Rook/Lance) |

> Since the board is exactly 9×9, using kernel size 9 (padding 4) gives every position "global visibility" of its row and column in a single layer.

### 4. MLP (Feed-Forward)

Follow the depthwise mixing with the standard "NeXt" pointwise structure:

```
LayerNorm
Linear(dim, 4*dim) → GELU → Linear(4*dim, dim)
```

## Alternative: Isotropic ConvNeXt

If you prefer the simpler ConvNeXt design, it is also a strong choice with isotropic scaling (no downsampling).

- Kernel size: `7×7` or `9×9` Depthwise Convolutions
- On a 9×9 board, a `7×7` kernel is nearly global — it acts almost like a Vision Transformer's attention, allowing pieces to "see" almost the entire board at once.
- Pros: Simpler to implement
- Cons: Slightly heavier computation for the same receptive field (negligible at 9×9)

## Final Verdict

Use **Isotropic InceptionNeXt** with:

- Kernel sizes: `3×3`, `1×9`, `9×1` [2]
- Depth: 10–20 blocks
- Hidden dimension: 128 or 256 (depending on compute budget)

This architecture explicitly models the geometry of the Shogi board (orthogonality) while maintaining the modern training stability of the "NeXt" family.
